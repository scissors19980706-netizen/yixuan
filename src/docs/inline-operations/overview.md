# Inline Operations 概览

Inline Operations 是 CatPaw 的核心功能之一，允许您直接在代码编辑器中与 AI 进行交互，无需切换到其他界面。

## 什么是 Inline Operations

Inline Operations 提供了一种无缝的方式来：
- 在代码上下文中直接获得 AI 帮助
- 快速执行常见的代码操作
- 保持编程流程的连续性

## 主要特性

### 🎯 上下文感知
AI 能够理解您当前的代码上下文，提供更精准的建议和操作。

### ⚡ 快速响应
无需离开编辑器，即时获得 AI 反馈和代码修改建议。

### 🔧 多样化操作
支持代码解释、重构、优化、测试生成等多种操作类型。

## 如何使用

### 基本操作流程

1. **选择代码**: 在编辑器中选中需要处理的代码段
2. **触发 Inline**: 使用快捷键 `Ctrl/Cmd + K` 或右键菜单
3. **输入指令**: 在弹出的输入框中描述您的需求
4. **查看结果**: AI 会直接在编辑器中显示建议或修改

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 打开 Inline Operations |
| `Enter` | 确认并应用建议 |
| `Esc` | 取消操作 |
| `Tab` | 接受部分建议 |

## 常用操作类型

### 代码解释
```
选中代码 → "解释这段代码的作用"
```
AI 会提供详细的代码解释和逻辑说明。

### 代码重构
```
选中函数 → "重构这个函数，提高可读性"
```
AI 会建议更清晰、更易维护的代码结构。

### 性能优化
```
选中代码 → "优化这段代码的性能"
```
AI 会分析并提供性能改进建议。

### 错误修复
```
选中报错代码 → "修复这个错误"
```
AI 会识别问题并提供修复方案。

### 测试生成
```
选中函数 → "为这个函数生成单元测试"
```
AI 会生成相应的测试代码。

### 文档生成
```
选中函数 → "为这个函数添加 JSDoc 注释"
```
AI 会生成标准格式的文档注释。

## 最佳实践

### 1. 提供清晰的指令
- ✅ "将这个函数重构为使用 async/await"
- ❌ "改进这个代码"

### 2. 选择合适的代码范围
- 选择完整的逻辑单元（函数、类、代码块）
- 避免选择不完整的代码片段

### 3. 利用上下文信息
- 确保相关的导入语句和依赖在视野范围内
- 选择包含必要上下文的代码段

### 4. 迭代改进
- 可以对 AI 的建议进行进一步的 Inline 操作
- 逐步完善代码质量

## 支持的编程语言

Inline Operations 支持主流编程语言：

- **JavaScript/TypeScript**: 全功能支持
- **Python**: 全功能支持
- **Java**: 全功能支持
- **Go**: 全功能支持
- **C++/C**: 基础支持
- **Rust**: 基础支持
- **其他语言**: 持续扩展中

## 注意事项

### 网络要求
- 需要稳定的网络连接
- 建议在良好的网络环境下使用

### 代码安全
- 代码内容会发送到 AI 服务进行处理
- 请遵循公司的代码安全政策

### 性能考虑
- 大型代码文件可能需要更长的处理时间
- 建议对较小的代码段进行操作以获得最佳体验

## 故障排除

### 操作无响应
1. 检查网络连接
2. 确认已正确登录 CatPaw
3. 重启 IDE 后重试

### 建议质量不佳
1. 提供更具体的指令
2. 选择更完整的代码上下文
3. 尝试分解复杂的操作为多个简单步骤
