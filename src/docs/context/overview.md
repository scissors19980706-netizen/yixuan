# 上下文管理概览

上下文管理是 CatPaw 的核心功能，它决定了 AI 对您的代码和项目的理解程度。良好的上下文管理能显著提升 AI 回答的准确性和实用性。

## 什么是上下文

上下文是 AI 在回答问题或执行任务时所参考的信息集合，包括：

- **代码文件**: 相关的源代码文件
- **项目结构**: 文件夹组织和依赖关系
- **文档资料**: README、API 文档等
- **错误信息**: 编译错误、运行时错误
- **外部资源**: 网页内容、技术文档

## 为什么上下文重要

### 提升回答准确性
```
❌ 没有上下文: "如何修复这个错误？"
✅ 有上下文: "@file App.js @linter-error 如何修复这个 TypeScript 类型错误？"
```

### 获得项目特定建议
AI 能够基于您的项目架构、编码风格和技术栈提供定制化建议。

### 减少沟通成本
无需重复解释项目背景，AI 能直接理解您的开发环境。

## 上下文类型

### @ Symbols 快速添加

CatPaw 提供了便捷的 `@` 符号来快速添加不同类型的上下文：

| 符号 | 功能 | 示例 |
|------|------|------|
| `@file` | 添加特定文件 | `@file src/utils.js` |
| `@folder` | 添加整个文件夹 | `@folder src/components` |
| `@codebase` | 搜索代码库 | `@codebase authentication` |
| `@web` | 添加网页内容 | `@web https://docs.react.dev` |
| `@linter-error` | 添加错误信息 | `@linter-error` |
| `@rules` | 添加项目规则 | `@rules` |
| `@docs` | 添加文档 | `@docs API.md` |
| `@url` | 添加 URL 内容 | `@url github.com/user/repo` |
| `@diff` | 添加代码差异 | `@diff` |

### 手动添加上下文

除了 `@` 符号，您还可以通过以下方式添加上下文：

- **代码片段选择**: 在编辑器中选中代码后添加到对话
- **终端内容**: 将终端输出添加到上下文
- **文件拖拽**: 直接拖拽文件到对话窗口

## 上下文管理最佳实践

### 1. 渐进式添加上下文

从最相关的文件开始，逐步添加更多上下文：

```
第一轮: @file main.js
第二轮: @file utils.js @file config.js
第三轮: @folder src/components
```

### 2. 保持上下文相关性

只添加与当前问题相关的上下文，避免信息过载：

```
✅ 调试登录问题: @file auth.js @file login.component.js
❌ 调试登录问题: @folder src (包含所有文件)
```

### 3. 及时更新上下文

当代码发生变化时，记得更新相关的上下文信息。

### 4. 利用项目索引

CatPaw 会自动为您的项目建立索引，`@codebase` 搜索能快速找到相关代码。

## 上下文限制与优化

### 上下文大小限制

- 单次对话的上下文有大小限制
- 优先添加最相关的文件和信息
- 使用 `@codebase` 搜索替代添加大量文件

### 性能优化建议

1. **精确搜索**: 使用具体的搜索关键词
2. **分层添加**: 先添加核心文件，再添加辅助文件
3. **定期清理**: 移除不再相关的上下文

## 实际使用示例

### 调试错误
```
@file src/api/user.js @linter-error
这个 API 调用为什么返回 undefined？
```

### 代码重构
```
@file src/components/UserList.js @file src/hooks/useUsers.js
如何将这个组件重构为使用自定义 Hook？
```

### 功能开发
```
@folder src/auth @docs authentication.md
基于现有的认证系统，如何添加双因子认证？
```

### 性能优化
```
@file src/utils/dataProcessor.js @web https://web.dev/performance
这个数据处理函数如何优化性能？
```

## 高级功能

### 智能上下文建议

CatPaw 会根据您的问题自动建议相关的上下文：

```
你: "如何修复这个 React 组件的渲染问题？"
CatPaw: "建议添加 @file Component.jsx 和 @linter-error 以获得更好的帮助"
```

### 上下文历史

查看和管理之前对话中使用的上下文，便于复用和参考。

### 项目模板

为常见的项目类型预设上下文模板，快速开始对话。

## 故障排除

### 上下文加载失败
1. 检查文件路径是否正确
2. 确认文件权限设置
3. 重新索引项目

### AI 理解偏差
1. 添加更多相关上下文
2. 使用更具体的描述
3. 分解复杂问题为简单步骤
