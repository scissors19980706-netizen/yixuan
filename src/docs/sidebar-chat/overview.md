# 侧边栏对话

CatPaw 的侧边栏对话功能为开发者提供了一个强大的 AI 助手界面，支持多种交互模式和智能功能。

## 功能概览

### Ask 模式
- **快速问答**: 针对具体问题获得即时回答
- **代码解释**: 理解复杂代码逻辑
- **错误诊断**: 快速定位和解决问题

### Agent 模式
- **任务执行**: AI 自主完成复杂编程任务
- **工具调用**: 集成多种开发工具
- **智能推理**: 基于上下文进行深度分析

### 自定义 Agent
- **个性化配置**: 根据项目需求定制 AI 行为
- **快捷方式**: 创建常用操作的快速入口
- **对话管理**: 灵活管理多个对话会话

## 使用场景

1. **代码审查**: 让 AI 帮助检查代码质量
2. **功能开发**: 协助实现新功能
3. **问题调试**: 快速定位和修复 bug
4. **学习提升**: 了解最佳实践和新技术

## 快速开始

1. 打开 CatPaw 侧边栏
2. 选择合适的对话模式
3. 输入您的问题或需求
4. 查看 AI 的回答和建议

更多详细信息请查看各个模式的具体文档。
