# 概览

欢迎使用 CatPaw！CatPaw 是一款强大的 AI 编程助手，旨在提升开发者的编程效率和体验。

## 主要功能

### 🚀 代码补全
智能代码补全功能，基于上下文提供精准的代码建议。

### 💬 侧边栏对话
与 AI 助手进行实时对话，获取编程帮助和建议。

### ⚡ Inline Operations
在代码编辑器中直接进行 AI 操作，无需切换界面。

### 🔍 上下文管理
智能管理代码上下文，提供更准确的 AI 响应。

- **JetBrains IDE**: IntelliJ IDEA, WebStorm, PyCharm 等
- **操作系统**: Windows, macOS, Linux
- **网络**: 需要稳定的网络连接
