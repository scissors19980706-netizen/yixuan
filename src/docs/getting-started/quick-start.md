# 快速入门

本指南将帮助您在 5 分钟内快速上手 CatPaw 的核心功能。

## 第一步：验证安装

确保 CatPaw 已正确安装并登录：

1. 在 IDE 右下角查看 CatPaw 图标
2. 点击图标，确认显示"已登录"状态
3. 如未登录，点击"请登录"完成认证

## 第二步：体验代码补全

### 智能补全
在任意代码文件中开始输入，CatPaw 会自动提供智能建议：

```javascript
// 输入函数名，CatPaw 会建议完整实现
function calculateSum(a, b) {
  // CatPaw 自动建议: return a + b;
}
```

### 快捷键
- `Tab`: 接受当前建议
- `Esc`: 取消建议
- `Ctrl/Cmd + Space`: 手动触发补全

## 第三步：使用侧边栏对话

### 打开对话面板
1. 点击 IDE 侧边栏的 CatPaw 图标
2. 或使用快捷键 `Ctrl/Cmd + Shift + C`

### Ask 模式快速问答
```
你: 如何在 JavaScript 中实现防抖函数？
CatPaw: 防抖函数可以这样实现...
```

### Agent 模式任务执行
```
你: 帮我重构这个函数，使其更易读
CatPaw: 我来帮您重构这个函数...
```

## 第四步：Inline Operations

### 代码内直接操作
1. 选中一段代码
2. 按 `Ctrl/Cmd + K` 打开 Inline 面板
3. 输入指令，如："添加注释"、"优化性能"

### 常用操作
- **解释代码**: 选中代码 → "解释这段代码"
- **生成测试**: 选中函数 → "为这个函数生成单元测试"
- **修复错误**: 选中报错代码 → "修复这个错误"

## 第五步：上下文管理

### 添加文件到上下文
使用 `@` 符号快速添加上下文：
- `@file` - 添加特定文件
- `@folder` - 添加整个文件夹
- `@codebase` - 搜索整个代码库

### 示例对话
```
你: @file package.json 这个项目使用了哪些主要依赖？
CatPaw: 根据您的 package.json 文件，主要依赖包括...
```

## 常见问题

### Q: 代码补全不工作？
A: 检查网络连接，确保已登录，重启 IDE 后重试。

### Q: 如何提高 AI 回答质量？
A: 提供更多上下文信息，使用 `@` 符号添加相关文件。

### Q: 支持哪些编程语言？
A: 支持主流编程语言，包括 JavaScript、Python、Java、Go 等。
